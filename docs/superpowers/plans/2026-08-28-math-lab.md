# 象限先生的数学实验室 — 实现计划

> **For agentic workers:** 按 Task 顺序执行，每完成一步更新任务清单并提交。

**Goal:** 交付一个仿照 liziwuli.com 的暗色主题初高中数学交互实验室（Next.js 15 + TS），首版含旗舰实验「函数图像与导数探究」。

**Architecture:** 单页应用：左侧课程目录（高中/初中双学段、搜索、免费体验）+ 右侧 Canvas 实验工作区。目录数据驱动（lib/catalog.ts）；表达式输入经安全解析器（lib/parser.ts）求值；lib/plotter.ts 纯函数绘制坐标系/曲线/切线；KaTeX 渲染公式；CSS 变量主题（暗/亮）。

**Tech Stack:** next@15（App Router）、react@19、typescript@5、katex、自研 Canvas 引擎。

## Task 3: lib/parser.ts 表达式解析器（核心）

- AST：num/var(x)/param(a-d)/unary/binary/call；Pratt 解析，优先级：+ - < * / 隐式乘 < 一元符号 < ^（右结合，-3^2 = -(3^2)）< 函数调用/括号 < 字面量
- 函数白名单：sin cos tan asin acos atan ln log2 log10 abs sqrt exp sign floor ceil
- 常量 pi、e；参数变量 x 及 a b c d；隐式乘法（2x、(x+1)2、2sin(x)）
- 非法输入抛 ParseError（中文信息，含位置）；除零/定义域外返回 NaN（不抛）
- API：parse(input):Expr；makeEvaluator(expr,params):(x:number)=>number；parseAndMakeEvaluator(input):{ok:true,fn}|{ok:false,error}
- 实现要点：先词法（数字/标识符/运算符/括号/逗号），后 Pratt 递归；e 作为常量但 e^(...) 需在词法处理指数记号（用 ^ 运算符即可，e 是标识符常量）

## Task 4: lib/math.ts + lib/plotter.ts 绘制引擎

- math.ts：clamp/lerp/roundNice（取 1/2/5×10^k 步长）/niceTicks(min,max,target):{ticks,step}/fmt(v,digits=2)
- plotter.ts：interface Viewport {xMin,xMax,yMin,yMax}；toScreen/toWorld；drawGrid（网格+加粗轴+刻度标签+O 原点）；drawCurve(fn,color,width)（逐像素采样，NaN/Inf 断点）；drawTangent(x0,y0,slope,color)（延伸至边缘）；drawArea(fn,a,b,color)（中点黎曼和填充）；drawMarker(x,y,label,color)；drawAxesLabels
- 主题色通过参数传入（不读 DOM）：grid/axis/accent/accent2/fill/label

## Task 5: lib/derivatives.ts 预设与导数

- interface Preset {id; name; expr; desc; derivativeExpr; formula: string[]; points?: {label; formula}[]; warn; params?: {name; min; max; step; def}[]}
- PRESETS 7 个：quadratic('a*x^2 + b*x + c') / cubic('x^3 - 3*x + a') / sine('a*sin(b*x + c) + d') / exponential('a*e^(b*x) + c') / logarithmic('a*ln(b*x + c)') / reciprocal('a/(x - b) + c') / damped('a*x*sin(x)')；每个带 公式数组（f(x)、f'(x)、额外推导）与易错点
- numericDerivative(f,x)：中心差分 h=max(1,|x|)*1e-4
- slopeOf(exprText, params, x)：命中预设解析导数，否则数值微分
- 预设跨学段共用（同一实验）
